# Contributing Guide

Thank you for your interest in contributing to the Laboratory & Enterprise Software Management System.

## Project Structure

The project is organized into independent components:

- `instrument-service` — laboratory instrument management microservice
- `experiment-service` — laboratory experiment management microservice
- `frontend` — browser-based laboratory dashboard
- `docs` — technical and architecture documentation

## Development Requirements

Before making changes, ensure you have:

- Java 17
- Maven
- Docker
- Docker Compose
- Git
